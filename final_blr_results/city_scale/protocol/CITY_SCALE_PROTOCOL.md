# v2n frozen Bengaluru protocol

Frozen before v2n inference or Integrated Gradients. This is an exploratory engineering and diagnostic round on a repeatedly examined Bengaluru dataset. Historical scores and test decisions are immutable. No training, feature invention, or new data collection is authorized.

## Canonical objects and compatibility gate

The canonical road graph is `data/graphs/bangalore_utm_nodes.parquet` plus `bangalore_utm_edges.parquet`; its message-passing serialization is `data/processed/graph/topology_graph.pt`, with 64 induced partitions in `partitioned_manifold_64_clusters.pt`. The validated forecast graph is the separate 15-station directed four-nearest-neighbor distance graph built by `src/stpignn/station_graph.py`/the v2j benchmark. Graph identities, edge direction, CRS, snapping, node-hour coverage, feature units, cutoff timing, residual anchor, scaler and full checkpoint state must agree with the intended model before a forward pass. Tensor dimensional agreement alone is insufficient. A material incompatibility blocks city inference. No road node is assumed to carry a measured label.

Existing corrected v2j ST-PIGNN predictions have no known saved matching neural weights; v2m MLP and TCN checkpoints use cutoff-safe weather and no graph or physics penalty. Historical `citywide_stpignn_best.pt` and `results/checkpoints_v2*` are separate protocols until proven otherwise. A checkpoint is usable only after architecture/state keys, feature schema, scaler, output reconstruction and graph inputs are verified. Do not adapt a historical checkpoint silently.

## Fixed city execution and measurements

If and only if the compatibility gate passes, run a small subgraph, a medium subgraph, then the full road graph. For partition execution, include all message-passing-hop halo nodes and compare output on an overlapping feasible subgraph to full-subgraph output; require maximum absolute difference at most 1e-5 µg/m³ and mean at most 1e-6. Use the first, middle and last available test cutoff UTC timestamps, ordered independently of predictions, and horizons 1, 3, 6, 12, 24 h. Check every output finite, unique node/time/horizon coverage, SHA-256, repeat-run maximum difference at most 1e-5 µg/m³. Record wall time, nodes/s, peak process RAM and CUDA allocated/reserved memory where available. Stop on missing temporal feature provenance, unsafe memory, nonfinite result, incompatible checkpoint or missing halo equivalence. A full forward pass without independent observations is at most a technical demonstration or experimental estimate; road-node accuracy requires independent spatial targets.

## Spatial validation

Reuse saved v2j W6 LOSO/interpolation results on their exact scored population; never train. Keep all 15 folds and report four unscored folds. Require held-out station pollution exclusion from inputs, imputation, fitting, graph priors, calibration and selection. Compare methods on identical station/UTC target pairs where saved artifacts permit; report per-station MAE, RMSE, R², n, pooled values and original uncertainty tests. Eleven scored stations are eleven spatial sites, regardless of timestamp count. No inference about road-node accuracy follows from station holdout or structural graph integrity.

## Captum IG fixed design

Use `captum.attr.IntegratedGradients` only for an exactly restored checkpoint with wrapper-equivalent final PM2.5 forecast. Primary input baseline: per-feature/hour/station training-set mean in the model's fitted input space, computed from training indices only. Sensitivity baseline: all-zero standardized input, with calendar channels set to their training mean if those channels are unscaled. Never select baseline by output. Select the lexicographically first, median and last station IDs with observed test targets; within each selected station and horizon select first, median and last valid test target times. Selection uses masks/IDs only, before prediction errors or attributions. Primary coverage: each model/horizon seed 11 at these nine examples, both baselines. Seed variability: all other available compatible seeds at horizon 6 on the median-time example for each selected station, primary baseline. If resource limits require less, preserve the ordered prefix and report skipped IDs. Fixed horizons are 1, 3, 6, 12, 24 h. IG uses 64 Gauss-Legendre steps, internal batch size 16, float32, fixed seeds and no dropout. Keep graph edges and neighbor inputs fixed for graph models unless the wrapper explicitly attributes them. Record 12-lag × 18-channel signed tensors and absolute summaries; mean signed and mean absolute are computed separately, never absolute of a signed mean. Wind direction is circular and reported by its actual feature coding; no causal reading. Convergence delta is reported per example in µg/m³ and relative to `max(1, abs(f(x)-f(baseline)))`; flag relative delta above 1% or absolute delta above 0.05 µg/m³, any nonfinite value, or wrapper mismatch above 1e-4 µg/m³. Report both baselines separately, no cherry-picking. Physics/λ0/Laplacian comparison requires matching corrected checkpoints; missing weights make it UNVERIFIABLE.

## Resource and claim stops

No new training. Cap IG at the declared sample set, two baselines and 64 steps; use one model process at a time. Stop a dependent path on missing checkpoint, missing model input, nonfinite output, bad wrapper equivalence or untenable memory. Preserve all other workstreams. The only possible city output labels are VALIDATED ROAD-NODE PREDICTIONS, EXPERIMENTAL ROAD-NODE ESTIMATES, TECHNICAL INFERENCE DEMONSTRATION, or BLOCKED. Use scientific claim classes SUPPORTED, MIXED, UNSUPPORTED, INCONCLUSIVE and NOT EVALUATED with exact source artifacts and limitations. No Captum result proves transport, conservation, causal effect, or road accuracy.
