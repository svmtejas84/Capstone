## Research questions and frozen comparisons

1. **Graph-edge necessity:** G0 existing unregularized GINEConv–GRU on the original station kNN graph; G1 exact one self-loop per node and no inter-station edge; G2 degree-preserving directed edge rewiring using fixed NumPy seed **5505**, swapping destinations only if the resulting arcs are distinct and not self loops. Recompute geometric edge distances from the two new endpoint coordinates. For G1, edge distance is zero. No original edge geometry is reused on a new pair. G0 reuses V3 zero checkpoints/predictions; G1/G2 are new fits. G0−G1 and G0−G2 across all five horizons form a **10-contrast V5 graph family**. Negative paired MAE difference favors G0.
2. **Lag-24 information parity:** L0 existing V3 unregularized 12-hour GINEConv–GRU; L1 same 12-hour network with three extra channels **only in the final input row**: log1p PM2.5 from an actually observed T−24 row if that timestamp is strictly before issue, otherwise the strict-prior issue anchor/fallback; binary genuine-daily-lag availability; capped age of actual source observation (0–168 hours divided by 168, or 1 for no actual observation). PM2.5 transformed with the existing train-only target log mean/SD. No target at or after issue enters. L2 unchanged 18-channel network with a 36-hour window, left-padding initial history with the first eligible array row to preserve target masks. L0−L1 and L0−L2 across five horizons form a **10-contrast V5 temporal family**. Existing same-hour-yesterday is the fixed simple daily-lag baseline; its true observation availability and fallback are reported. Input channel count and parameter count will be recorded. The graph remains G0 for all L variants. No new model architecture or LR search.
3. **Six-hour regularizer fairness:** zero penalty and six nonzero families: actual wind; within-month shuffled wind; full-training-calendar shuffled wind; 180° reversed wind; constant 0° north wind-to bearing; undirected Laplacian. For each nonzero family, λ∈{0.06,0.3,1.0} using the same five-epoch linear warmup. The existing V3/V4 λ=.06 fits and true-wind λ=.3/1.0 are reused if their configuration and source hashes pass verification. Missing cells will be newly trained. A family coefficient is selected by the **lowest mean validation MAE across all five fixed seeds**, tie broken by lower λ. The complete validation grid and all predeclared exposed-test grid outcomes will be reported; no coefficient is chosen on test performance. The V4 magnitude-matched Laplacian coefficient 0.02184366393360663, matched by raw penalty on one frozen training batch (not gradients), remains a separate historical reference, outside the three-value grid. The six family-procedure contrasts versus true wind form a **later exploratory six-member family**, not a retroactive extension of V3's frozen 20-member family.
