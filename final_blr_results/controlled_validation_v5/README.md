# Controlled validation V5

This isolated package tests graph-edge necessity, daily-lag information parity and six-hour regularizer-family fairness on the **previously exposed** Bengaluru test population. It reuses frozen V3/V4 arrays, checkpoints and predictions. No V3/V4 files are modified. The original 15-station graph is separate from the historical 154,902-node road graph. Forecast weather is timestamp-causal archived historical observation; operational release timing is unverified.

Read `PROTOCOL_FREEZE.md` and both pretest amendments before interpreting results. `DATA_ELIGIBILITY.md`, `FORECAST_LEAD_AND_INFORMATION_PARITY.md`, `ANCHOR_AGE_AUDIT.md` and `SAVED_CONTRAST_AND_PENALTY_AUDIT.md` document the saved-data controls. `COMPLETE_IMPLEMENTATION_REGISTER.md` describes model and input semantics. New training and test outputs are under V5 `training/`, `predictions/`, `metrics/`, `statistical_analysis/` and `figures/`.
