# Forecast origin, issue time and strict observation cutoff

For target hour T and horizon h, the V3 issue hour is c=T−h (`scripts/benchmark_v2j.py:Context.batches`, overridden by `final_blr_results/controlled_validation_v3/scripts/smoke_gpu.py:CutoffContext.batches`). The twelve feature rows are c−11 through c inclusive. In the repaired array, the pollutant channels displayed at c actually come from source row c−1. Since raw station timestamps are floored to their hour, an observation during c−1 can occur as late as c−1:59; it precedes c. The observed-target label at T is used only for loss/scoring. The residual anchor `input_anchor[c]` is the latest observed station PM2.5 from rows strictly before c, or a station training mean if none exists (`scripts/build_causal_array.py`). The missingness flag at c is based on observed pollutant status at c−1. Weather at c is the archive observation labeled c−30 minutes; publication delay is unknown. Wind masks use wind at c. No issued weather forecast is present.

Concrete example: for T=2025-10-01 12:00 UTC and h=1, c=11:00. The last pollutant feature row represents hour 10:00, and the latest possible raw reading contributing to it is before 11:00; the weather source is the archived record stamped 10:30. The nominal one-hour model therefore uses pollutant observations **strictly earlier** than the 11:00 issue, not a confirmed 11:00 reading. This is timestamp causality only: sensor ingestion before 11:00 and weather archive publication before issue have not been independently verified.

The `same_hour_yesterday` baseline uses the observed value at T−24 only when h<24 and that observation is present. At h=24, T−24 equals issue c; a raw value assigned to c can occur after c. Therefore the implementation uses the strictly prior `anchor[c]` rather than that same-hour observation (`scripts/evaluate_baselines.py:52-55`). Missing previous-day observations at shorter horizons also use `anchor[T−24]`. At 24h, its saved predictions are identical to the persistence definition using `anchor[c]`, giving MAE **14.972188** µg/m³ on 14,583 pairs. At 1–12h the same-hour-yesterday baseline gives 14.130312 µg/m³. The different 24h value follows the frozen eligibility/fallback rule, not a changed target population. Historical 14.130 values must not be relabeled as 24h cutoff-safe performance.

The raw hourly output model does not establish operational lead time because release and ingestion latencies were not captured. A certified forecast would require source publication logs or an explicit latency buffer.
