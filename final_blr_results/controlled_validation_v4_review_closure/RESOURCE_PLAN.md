# Bounded V100 resource plan

Frozen before the 30-fit launch: one NVIDIA V100-PCIE-32GB, a 4 GPU-hour ceiling and 2 GiB maximum additional checkpoint storage. V3 repaired-array one-batch smoke allocated 1.212 GiB; V4 uses the same tensor shape and backbone. A conservative upper bound of 30 fits × 30 epochs × about 2 seconds per epoch is 1,800 seconds (0.5 V100-hour) of fit time, plus data loading, checkpoint writes and verification. The actual fit seconds are recorded in every `training/final/*/COMPLETE.json` and the supervisor attempt log. Each cell writes an atomic `partial.pt`, `best.pt`, `epochs.json` and `COMPLETE.json`; the single worker writes `training/final_COMPLETE`. The detached supervisor uses a lock and explicit run state under `logs/sensitivity`, with zero automatic restarts. A stopped run can be manually resumed after inspecting the attempt log; completed cells are skipped after array-hash verification. The host and GPU were checked before launch; no other V4 job was active. V3 source checkpoints and arrays are read-only.
