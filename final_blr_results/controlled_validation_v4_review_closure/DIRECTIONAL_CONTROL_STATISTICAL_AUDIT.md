# Complete frozen V3 directional-control statistics

`COMPLETE_20_CONTRAST_RESULTS.csv` contains all 20 prespecified five-horizon contrasts (true wind minus λ=0, within-month shuffled wind, +90° rotated wind, Laplacian). The V4 audit independently recomputed each point difference from aligned V3 per-pair NPZ files and matched the V3 frozen statistic to 2×10⁻⁵ µg/m³. `SEED_LEVEL_REGULARIZATION_RESULTS.csv` contains all 100 five-seed paired differences. Every ensemble contrast has 14,583 common observed target pairs and 177 observed UTC days; 26 nonoverlapping seven-day blocks enter the sign-flip test. The V3 script uses 2,000 moving seven-day block bootstrap draws for the 95% interval, 100,000 nonoverlapping-block sign-flip draws for p-values, and Holm adjustment across all 20 contrasts. The two uncertainty procedures use different block constructions; a bootstrap interval excluding zero need not agree with the sign-flip p-value. These results remain exploratory because the period was repeatedly examined.

At six hours, true minus λ=0 is **−0.128652 µg/m³**, seven-day moving-block CI **[−0.404159,+0.091673]**, so directional improvement is inconclusive. True minus within-month shuffled is −0.023941 with CI [−0.053679,+0.001996]. True minus rotated is −0.137190 with CI [−0.191375,−0.084549]. True minus Laplacian is −0.224795 with CI [−0.342078,−0.137387]. A better result against a comparator does not establish atmospheric specificity, especially where the true mask does not beat no regularization and penalty exposures differ. The V4 six-hour controls are a prespecified exploratory sensitivity, reported separately.
