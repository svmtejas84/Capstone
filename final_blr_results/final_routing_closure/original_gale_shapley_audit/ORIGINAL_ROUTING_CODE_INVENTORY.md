## Implementations found

| Component | Source | What it does | Status / limit |
|---|---|---|---|
| Serving route construction | `router/api/routes.py::_candidate_paths` (about lines 190–266) | Collapses a directed MultiDiGraph to a DiGraph; constructs dose A*, dose-ranked simple paths and distance alternatives; returns up to k routes after a mode-weighted dose/distance score. | Inference may fall back to persistence; not an evaluated exposure result. | Commuter preferences | `matcher/commuter_model.py::build_preference_list` | Mode-specific weighted normalized dose and distance-tolerance score. | Does not include travel time directly; stable ranking only over the supplied candidate list. |
| Corridor/route preferences | `matcher/segment_model.py::build_preference_list` | Scores vulnerability mode weight plus inverse `id_min`, divided by a congestion factor, then uses commuter ID as tie-break. | In current API the `Segment` has a route ID, and `congestion_penalty` defaults to zero; `cedge_mean` is not part of the preference score. Thus this is route-level priority, not a per-road-segment preference. |
| Serving matching | `matcher/gale_shapley.py::batch_match` (Git history contains an earlier 11-line round-robin version at `e1a31e7`, followed by the preference/capacity implementation in later revisions `a3cafa7`/`b88707e`) | Commuters propose to route IDs; each route holds up to a route quota and displaces its lowest-ranked held commuter. | No route-to-edge resource map; cannot enforce shared-road-edge capacities. | Assumed serving quota | `matcher/road_capacity.py::route_capacity` | Route quota from minimum road-class × lane × congestion capacity along that route, 900-second window and duration discount. | Capacity constants are assumed VPH/lane values, not observed Bengaluru counts. Quota is computed independently for every route, so overlaps are double-counted. |
| Offline evaluator | `scripts/evaluate_routing_gs.py::candidate_routes`, `edge_quotas`, `deferred_acceptance`, `simulate` (added in `7d8e7d2`) | Generates candidate route bundles and runs a distinct deferred-acceptance heuristic with directed-edge reservations, atomic path release on rejection, and a terminal capacity assertion. | Edge capacities are pollution-inverse heuristics. Bundle preferences do not satisfy the ordinary one-to-many Gale–Shapley model; no global stability or welfare result follows. |
