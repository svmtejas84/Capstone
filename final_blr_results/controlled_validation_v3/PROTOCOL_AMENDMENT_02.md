# Protocol amendment 02 — station observation hour-end correction

Frozen after a full raw-data future-mutation test failed, before any v3 test evaluation. `src/stpignn/data_v2.py:utc_hour` floors a station timestamp to its hour. A raw reading timestamped 12:30 UTC can therefore enter the station feature labeled 12:00 UTC, although it is unavailable at a 12:00 forecast issue. The synthetic component tests missed this. The full-pipeline test changed raw records strictly after 2025-10-01 12:00 UTC and changed 15 PM2.5 feature cells at that issue hour, plus other pollutant cells. Gate A failed. GPU worker was stopped after 20 LR-selection and 54 final cells; all are scientifically invalid for the intended cutoff-safe comparison, preserved under `training/invalidated_pre_causal_shift/`. No test metric was computed.

Correction: retain the original observed-target timestamp and mask for scoring. For each model feature hour c, use pollutant channels 0–4 and their imputation provenance from the preceding hourly row c−1. This guarantees a raw pollutant timestamp in hour c−1 cannot be later than c. The missingness flag at c is based on the preceding row's observed PM2.5 status. The residual anchor at c is the most recent observed target in rows strictly before c, with a training-only station-mean fallback. Meteorological channels remain at their timestamp-causal c−30-minute archive value. Calendar and static channels remain unchanged. The first row has no preceding pollutant observation and uses the training-derived fallback. No target label is moved or fabricated.

All selection and final cells must restart from scratch against a new versioned array with a new SHA-256. The original v2m array and historical experiments remain untouched. A full raw-data future-mutation test and a one-batch GPU smoke test must pass before restarting training. The test interval remains locked. This repair changes the input definition, so the old v2m MLP/TCN checkpoint predictions are no longer identical-input baselines; they require retraining under the new array or must be explicitly labeled cross-protocol. The latter cannot answer RQ1's matched-information question.

Operational weather release timing and station ingestion latency remain unverified. The corrected protocol is a timestamp-causal retrospective historical-observation experiment, not a certified operational forecast.
