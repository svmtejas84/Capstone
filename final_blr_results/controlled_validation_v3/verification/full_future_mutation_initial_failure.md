# Full-pipeline future-mutation failure (pre-repair)

The first raw-data mutation test changed station and weather rows whose raw timestamps were strictly after 2025-10-01 12:00 UTC, rebuilt the original `data_v2.build(..., weather_cutoff_safe=True)` features, and compared features through that issue time. It failed at issue-hour index 32,868, station index 0, feature 0 (PM2.5): standardized value 0.0055322819 before versus −0.0637099668 after. Changed-cell counts by the 13 base channels were `[15, 3, 3, 4, 4, 0, 0, 0, 0, 0, 0, 0, 0]`. The first changed time was exactly 2025-10-01 12:00 UTC. Source cause: `src/stpignn/data_v2.py:utc_hour` floors raw station timestamps to the hour. A measurement after 12:00 can therefore enter a row labeled 12:00.

This failure invalidated 20 validation-selection and 54 final v3 cells trained on the unshifted array. They are preserved at `training/invalidated_pre_causal_shift/` and their supervisor logs at `logs/selection/` and `logs/final/`. No test metric was computed. `PROTOCOL_AMENDMENT_02.md` and `scripts/build_causal_array.py` document the correction. The patched full raw-data mutation test passed after delaying pollutant inputs by one row; its machine-readable output is `verification/full_future_mutation.json`.
