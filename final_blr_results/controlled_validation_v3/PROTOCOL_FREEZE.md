# Controlled validation v3 — prospective analysis plan

Frozen before any v3 model fit or evaluation. Source branch: `research/controlled-validation-v3`; parent commit `bcfae630410ce5c91f7059284d16eebb9143d18f`. Historical Bengaluru test results are exposed. This campaign is exploratory unless a genuinely unused later temporal holdout is found and locked before its labels are inspected.

## Questions and populations

RQ1 compares the station GINEConv–GRU with statistical, temporal, and graph baselines on identical observed station–target pairs. RQ2 compares directional regularization with λ=0. RQ3 compares the actual direction with a fixed shuffled direction, +90° rotated direction, and Laplacian smoothing. RQ4 audits matched optimization, effective λ, and seeds. RQ5 evaluates independent temporal and separately station-isolated generalization only when eligible data and isolated preprocessing exist. No result from one RQ establishes another.

The frozen exploratory population is the 15 Bengaluru monitoring stations and observed PM2.5 targets in `configs/data_v2.yaml`: train 2022-01-01 to 2025-06-29 UTC, validation 2025-07-01 to 2025-09-21 UTC, exposed test 2025-09-23 to 2026-03-28 UTC, with 24-hour gaps. Horizons are 1, 3, 6, 12, 24 hours; 12 preceding hourly rows end at issue time T−h. Five seeds are 11, 23, 37, 51, 79. All available scored sites and eligible targets are retained; failures and exclusions are logged. A later holdout requires an addendum frozen after a metadata-only availability check, before target inspection. No later holdout is currently present in the saved array.

## Information set and leakage gate

Use an 18-channel station tensor: 13 corrected pollutant/meteorological/static channels, lag-imputed flag, and four cyclic calendar channels. Use the v2m half-hour weather rule: for feature hour c, select a historical weather record timestamped at or before c (normally c−30 minutes). This is a **timestamp-causal historical-observation protocol**, not a certified operational weather forecast: Open-Meteo Archive has no verified issuance or release timestamp. Inputs at T−h and before may include contemporaneous observed station pollutants only if their observation timestamp is no later than T−h; their release latency remains an explicit limitation. All train-fitted medians, ratios, climatologies, scalers and graph coordinates are fixed using the training interval. Residual anchor is the last observed PM2.5 at or before issue time, with a training-derived fallback. Target masks score observed values only. Future-mutation tests must show that changing data after an issue time cannot change its features or anchor. Any violation blocks fitting until repaired and re-frozen.

The already saved `data_v2m_arrays.npz` is a candidate input, subject to leakage tests and source inspection. Historical centered-weather v2j inputs are ineligible for v3. Spatial LOSO is an optional separate population requiring fold-specific imputation/scaling that excludes held-out station targets everywhere; no spatial result is inferred from ordinary temporal evaluation.

## Models and optimization

The main backbone is the existing corrected 18-channel, 64-hidden, two-GINEConv plus GRU station model with 60 directed 4-neighbor station arcs and standardized log1p residual output. No architecture enlargement. Controls share network initialization, graph, features, batches, masks, AdamW, weight decay 0.01, batch 512, gradient clipping 0.3, and masked squared error on standardized log1p output. Statistical controls: persistence, same-hour yesterday, station train mean, hour/day climatology, weather ridge. Neural controls: MLP, causal TCN, GRU-only, vanilla GCN, GRU–GCN, adaptive graph, and λ=0 GINEConv–GRU. All baseline inputs must be adapted from the same 18-channel tensor and issue-time information.

Matched regularization conditions: P0 λ=0; P1 original true-wind hinge; P2 hinge with a seed-fixed permutation of training wind-mask directions only (predictive weather features unchanged); P3 hinge with wind-mask directions rotated +90° only; P4 direction-independent Laplacian. The shuffle permutation is chosen from issue-time indices with seed 4303, separately within each split, without labels; it is never redrawn after test results. Geometry and penalty normalization otherwise match `src/stpignn/physics_v2.py`. Penalty exposure, active arcs, zero-arc batches and gradient norms are reported. No mass-conservation claim.

For Analysis A, select **one shared learning rate** from [0.0001, 0.0003, 0.001, 0.003] using seed-11 validation MAE of λ=0 at each horizon, then freeze it for all five matched variants and seeds at that horizon. Same seed means identical initial state and batch order across matched variants. AdamW runs at most 30 epochs, validation-MAE checkpoint selection, patience 5, and a minimum 10 training epochs before checkpoint selection so the regularizer acts. The primary schedule is λ(epoch)=0.06×min(1,epoch/5), fixed before comparison; λ=0 is zero. The historical 25-epoch schedule is a descriptive reference only. This schedule is a deliberate v3 change and cannot be compared as a strict historical reproduction. Analysis B (variant-specific validation-selected LR) is optional and separately labeled. No test-based setting changes. Optional λ=.03/.06/.12 and cone-width 45°/75°/120° sensitivity is validation-only, contingent on resource budget; default cone is 75°.

## Metrics, inference and decisions

Report MAE, RMSE, R², observed pair count, coverage, per-station MAE, five individual seeds and the fixed five-seed mean-prediction ensemble. Primary family: P1−P0, P1−P2, P1−P3, P1−P4 at all five horizons (20 contrasts), Holm adjusted. All signs are directional minus comparator; negative favors true wind. Seven-day moving-block bootstrap on paired UTC-day units gives exploratory 95% intervals; exact two-sided sign test for five paired seeds where appropriate. The exposed test period precludes confirmatory p-value claims. Station/site uncertainty is separate from time-block uncertainty. Baseline comparisons are descriptive unless independently held out.

Gate A: pass timestamp-cutoff and future-mutation tests, or stop neural fitting. Gate B: finite forward/backward, deterministic initialization, checkpoint round-trip and observed-mask metrics, or stop. Gate C: finish P0/P1 matched runs; Gate D: P2/P3/P4; Gate E: matched baselines; Gate F: one-time independent-test unlock only if new eligible data exist. Failed runs remain in the register. No horizon or seed is dropped after results.

## Resource and persistence ceiling

Before full execution, measure one-batch V100 memory and one-epoch pilot runtime. Expected core regularizer matrix: 5 horizons × 5 seeds × 5 conditions = 125 final fits, plus 20 seed-11 LR selection fits and baseline fits; this is a ceiling, not automatic launch approval. One GPU worker, no `tmux`; `scripts/run_supervised.sh`, atomic per-cell results and checkpoints, a single-instance lock, explicit completion markers and logs. Pause if projected resource use exceeds 24 V100 GPU-hours or 20 GiB new checkpoint storage; document the required additional budget. Preserve all source experiments. No paper or London work.
