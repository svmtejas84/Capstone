# Resource plan

Host read-only `nvidia-smi` returned Tesla V100-PCIE-32GB, 32,768 MiB total, 12 MiB used. The sandboxed Python process reports no CUDA device; authorized training commands therefore require the same approved elevated execution path used for the GPU check. This is an execution restriction, not evidence that the V100 is absent.

Valid rerun after Amendment 02: 125 final regularizer fits (5 horizons × 5 seeds × 5 variants) plus 20 seed-11 LR-selection fits for λ=0. Six same-information neural baselines (GRU-only, GCN, GRU–GCN, adaptive graph, MLP, TCN) add 120 LR-selection and 150 final fits, **415 valid cells total**. The 20 selection and 54 final cells attempted before the full data-integrity failure remain quarantined and count toward resource use; they are not valid scientific evidence. Historical MLP/TCN 50 final cells used 84.8 s total V100 fit time and ~120 MiB allocated peak, but this is **not** a GNN runtime estimate. The repaired-array GINEConv–GRU one-epoch pilot took 1.8025 s, 1.21 GB allocated peak; a 30-epoch upper bound across all 415 cells is roughly 6.2 GPU-hours of fit time before context build and checkpoint overhead. Measure actual total from cell records and stop if projected >24 V100 GPU-hours or >20 GiB new checkpoints. One worker only, `scripts/run_supervised.sh` with per-cell atomic artifacts, lock, logs and completion markers. Never rely on session persistence alone.
