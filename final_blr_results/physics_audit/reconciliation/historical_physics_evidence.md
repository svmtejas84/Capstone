Historical criteria were not changed. The W7 sweep was shifted-weather and many λ>0 settings were harmful; corrected-weather v2j uses fixed input repair and the benchmark selects LR by validation seed 11. The h=1/24 limited lambda run has its own selection, so its values need not equal benchmark ensembles exactly. No result is an independent replication because the Bengaluru test set has been repeatedly examined. The physical proxies do not uniquely favor upwind regularization.
