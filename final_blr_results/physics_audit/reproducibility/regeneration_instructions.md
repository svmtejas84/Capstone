# Regenerate v2l without model training

From repository root, run `bash final_blr_results/physics_audit/reproducibility/regenerate_v2l.sh`. The two Python modules read only the 75 local v2j benchmark prediction Parquets, the corrected v2j data/fit files, the saved benchmark selection/run tables, original v2k paired table and source/configuration files. They recompute per-seed, ensemble, monthly, bootstrap, multiplicity, selection/provenance and physical-proxy CSVs, the chart, and analysis manifest. They never import a training runner or write to historical `results/` prediction paths. Written outputs are restricted to `final_blr_results/physics_audit/`.

`artifact_checksums.csv` gives SHA-256 values for every required historical prediction and ancillary source/config/metric/log input. Verify all required local hashes against it before interpreting a regeneration; mismatches require investigation, not silent substitution. `analysis_manifest.json` records input paths, script hash, dataset hash, source commit and statistical parameters. The final report texts are human interpretations of these generated tables; if inputs change, review and update those texts separately. Older `results/checkpoints_v2*` weights are not required and are not valid corrected-v2j checkpoints.

No independent durable backup of the required local ignored prediction caches was verified. GitHub stores lightweight tracked summaries and this audit, not the full prediction cache. The local April 2026 tarball is on the same filesystem and predates v2j. Do not call this audit independently archived until an approved off-host destination has received files and remote checksums have been verified. Backup procedure: `final_blr_results/archive/reproducibility_status.md`.
