# Provenance and controlled-comparison review

`model_configurations.csv` lists all 75 model/horizon/seed cells. Training ran under `results/codex_log/runs/benchmark_gpu_v2j/execution_manifest.json` (V100; launch commit `9a299f1bf01787f26750515cad8dff370e9c9aa0`), with the same benchmark, model, physics and YAML source at the horizon-completion commit `a736005077104f01d0ab1006ba7dc12daae0d403`. The manifest's config and seed fields were null, but the saved source, YAML, selection table, test-run rows, and 75 Parquet file labels establish actual settings. Source `scripts/benchmark_v2j.py:137-209,265-324` and `src/stpignn/models_v2.py` call exactly the same 43,393-parameter ST-PIGNN for all three variants. Their forward graph, edge distances, inputs, target transformation, residual formulation, optimizer budget and test mask are shared. The loss condition alone switches among no regularizer, masked upwind hinge, and Laplacian squared edge difference. For the two regularized variants, the nominal λ=0.06 is ramped by `min(1,epoch/25)`; it is not 0.06 throughout training.

`prediction_integrity.csv` verifies all 75 files exist, each has 14,583 finite observed targets inside 0–500 µg/m³, 11 target station IDs, 177 observed UTC days, no duplicate key, and byte-identical sorted `(timestamp,station)` keys and target values. Zero pairs were dropped or intersected. `results/data_v2j_fit.json` records the corrected weather flag; every prediction path was generated by `Context` loading `results/data_v2j_arrays.npz`. No imputed target is scored as truth. Dataset hash is recorded in the CSV and methodology. No corrected benchmark checkpoint for any of the three variants was saved; older `.pt` files in `results/checkpoints_v2*` belong to prior datasets/protocols and cannot validate these v2j weights.

The comparison is a **controlled ablation of the validation-selected training procedure**: architecture/data/masks are equivalent, and only the declared regularizer differs in code. It is not a fixed-LR, fixed-epoch causal estimate of the penalty alone, because each variant independently selects an LR on seed-11 validation MAE and then early-stops each seed; selected LRs differ at h=1,6,12,24. Repeated test exposure and W7 history further limit attribution. The v2j limited lambda check (`results/lambda_check_v2j.csv`) is a separate run with its own selections and should not be merged into benchmark rows.
