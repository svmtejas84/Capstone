# Paired UTC-day bootstrap verification

`scripts/summarize_benchmark_v2j.py:21-41` and `final_blr_results/baselines/compare_saved_predictions_v2k.py` both group paired station-hour errors by UTC target day. The v2k comparison sums per-day absolute-error differences D_d and counts n_d, samples **the same day indices** for both models, and calculates `ΣD_d/Σn_d` over 2,000 draws. Percentile 2.5/97.5 intervals are nominal 95% intervals. Counts preserve unequal station observations per day, so this estimates the observation-weighted pooled MAE difference; it does not equally weight days. The grouping keeps within-day cross-station dependence intact. All 75 files have identical 14,583 keys/targets, and no NaN or missing comparison pair was removed. Eleven stations and 177 UTC days contribute per horizon.

The original v2k physics-versus-λ=0 intervals were reproduced from saved predictions using exact row-index seeds 4406, 4613, 4920, 5527 and 6734 for h=1,3,6,12,24 respectively. Recomputed bounds match `paired_architecture_comparisons.csv` to float32/roundoff tolerance; no aggregate-MAE bootstrap was used. The v2l per-seed intervals use separate deterministic seeds stated in `run_physics_audit.py`. The bootstrap presumes days are exchangeable enough for resampling; adjacent-day pollution/weather dependence and the short seven-month test window make this assumption imperfect. The moving-block sensitivity is in `block_bootstrap_sensitivity.csv`.
