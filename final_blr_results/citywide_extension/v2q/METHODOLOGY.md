# v2q methodology

Recovery was static: parsed every notebook cell, its imports and paths; inspected `gnn/model.py`, `gnn/checkpoint.py`, `gnn/stpignn_inference.py`, `src/stpignn/legacy_canonical.py`; hashed notebook/source/checkpoints/data; strict-loaded the root best checkpoint on CPU. The notebook was never run as a whole. Historical replay evidence was read from `results/{audit_canonical,replay_canonical,full_replay_parity}.json`, with source hashes recorded in `RECOVERED_ARTIFACT_MANIFEST.csv`. Protocol was committed/pushed as `421c7d4` before any v2q decoder implementation/test.

The Path A gate required a forecast-origin input window with no target-hour pollutant field, honest temporal features for the chosen road nodes, matching checkpoint semantics and graph neighborhoods. It failed on cell 5, cell 9 and saved data coverage. Path B feasibility used a fixed p=2 IDW function and a 32-hidden two-layer residual MLP, with only synthetic mathematical tests. It did **not** fit a model or evaluate Bengaluru targets, because no common target-excluding fold support forecasts survive. Reporting `NOT RUN` preserves the distinction between feasibility code and scientific evidence. Full-city execution was gated out before generating any new predictions.
