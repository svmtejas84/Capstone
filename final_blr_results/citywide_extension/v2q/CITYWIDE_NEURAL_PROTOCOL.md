# v2q citywide neural protocol — frozen before any new evaluation

Frozen 2026-11-06 after static recovery of production notebook and original artifacts. This is an exploratory engineering round on previously exposed Bengaluru data. No Bengaluru result can become independent confirmatory evidence. No new neural architecture search, road-node label fabrication, London study, RGDR study or paper writing.

## Forecast task and information set

- Forecast origin `τ` is the end of the last *observed* hourly input. Candidate horizons are the existing 1, 3, 6, 12 and 24 hours; any bounded pilot uses **h=6** only because it is the existing W6 spatial-validation comparison, not because of v2q outcome selection. A future target is PM2.5 observed at a monitoring station at `τ+h`. Road-node values, if produced, are estimated concentrations, never road observations.
- All pollutant lags, weather, quality flags and spatial-support features must have availability time no later than `τ`. In particular, no `τ+h` monitor reading may be used to construct an input. Archived historical weather and v2j/v2m weather protocols must remain labeled separately.
- Road topology is `data/processed/graph/topology_graph_pyg_inference.pt`: 154,902 nodes, 424,550 arcs. The corrected forecast graph is the separate 15-station/60-arc kNN graph. No road edge is assumed to be a calibrated atmospheric transport edge. Road coordinates and verified SRTM elevation may be covariates; synthetic graph elevation is excluded.

## Candidate paths, fixed order

1. **Legacy restoration:** root `citywide_stpignn_best.pt` is only a historical 16-channel, direct one-step, 64-partition checkpoint. A small strict-load/forward parity test may reproduce the archived implementation. It cannot support a new forecast or road accuracy claim unless its time alignment, feature provenance, station isolation and boundary arcs are repaired without changing what the weights mean. Such repair will generally invalidate the saved weights; then stop Path A.
2. **Station forecast + spatial bridge:** use only station forecasts generated at `τ` by an eligible saved model or a small, bounded, train/validation-only pilot. Compare on the exact same held-out station × target hour mask: (a) training-only mean, (b) station forecast + prespecified IDW p=2, (c) compact spatial decoder. All support stations' predictions must themselves be trained without the held-out station's targets or target-derived features. The decoder may use coordinates, verified elevation and distance/support diagnostics, with train-fold-only scaling. Use leave-one-station-out (LOSO); report each site, not timestamps as independent sites. No same-hour observed PM2.5 in a forecasting control.
3. **New full-road temporal model:** protocol only if A/B fail. It requires real road supervision or a defensible labeled target population, complete forecast-eligible temporal node features, graph-compatible edge semantics, spatial holdouts and a measured pilot budget. No such training is authorized now.

## Selection, metrics, and gates

- Freeze h=6, station IDs and masks from the existing corrected W6 LOSO protocol if a pilot is possible. Preserve four unscored stations explicitly. No configuration, IDW power, network width or threshold may be selected using exposed Bengaluru test outcomes. For feasibility, a decoder is at most a two-layer 32-hidden MLP with distance-weighted forecast summary and static geographic inputs, trained on training folds only; one seed 42, at most ten epochs, early stopping on validation only. This is an engineering pilot, not an architecture search.
- Metrics: MAE, RMSE, R² (only where defined), coverage, per-station observations, nearest-support distance, wall time, CPU RSS, GPU VRAM if used, finite/output-completeness checks. Compare exact paired rows; record failed coverage rather than silently dropping it. Numerical repeat tolerance for a deterministic CPU forward is absolute 1e-5 in normalized units; all generated outputs must be finite, keyed uniquely by node/time/horizon.
- City execution, if gated in, proceeds 1,000 nodes, 10,000 nodes, then all 154,902; preserve global node mapping and compare overlapping partition/full-graph two-hop neighborhoods. Declare output **experimental neural-assisted road estimates** unless independent road sensors validate them. A CPU pilot should stay below 2 GB RSS and 30 minutes; no long GPU campaign. Stop on future-target leakage, unavailable compatible forecast checkpoint, missing road-node covariates, untested station isolation, non-finite outputs or weak decoder validation relative to simple controls.

Existing corrected W6 LOSO is unfavorable (ST-PIGNN MAE 22.314 versus ridge 20.624 µg/m³ on eleven scored stations). Existing v2o same-hour IDW is retrospective and must not be compared as h-step forecasting. This freeze precedes any new v2q model fit or forecast evaluation.
