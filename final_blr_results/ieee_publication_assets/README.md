# IEEE publication assets v2u

10 figure variants (eight requested groups), 10 table files (eight requested groups), 17 distinct directly plotted source artifacts.

All plots and tables derive from frozen Bengaluru results. `scripts/build_assets.py` regenerates figures; `scripts/build_tables.py` regenerates tables; `scripts/verify_package.py` checks sources and archives.

The corrected 15-station forecasting model is separate from the 154,902-node road graph. Citywide values are experimental neural-assisted estimates, and routing dose is modeled. v2j and v2m weather protocols differ.

See `methodology/ASSET_PROTOCOL.md`, `source_data/figure_manifest.json`, `tables/table_manifest.csv`, and `FINAL_PUBLICATION_ASSET_HANDOFF.md`.
