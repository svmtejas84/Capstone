- **Architecture:** depict the corrected 15-station, 60-directed-edge kNN forecasting graph (18 inputs, 12 hours, horizons 1/3/6/12/24 h). Put the 154,902-node road decoder/routing extension in a separate dashed downstream lane. Directional hinge is a heuristic.
- **Geography:** use `data/graphs/bangalore_utm_nodes.parquet` and `bangalore_utm_edges.parquet` in EPSG:32643. Recover the stored 64 historical partition IDs from `data/processed/graph/partitioned_manifold_64_clusters.pt` using only the audited compatibility shell from `final_blr_results/road_graph/inspect_graph_v2k.py`. - **Forecasting:** source v2j metrics from the recomputed saved-prediction table, with MLP/TCN from v2m `ensemble_metrics.csv`. Keep weather protocols visible and do not pool them as identical-input ablations. All five horizons and unfavorable rows remain.

- **Spatial:** W6 raw train-mean ST-PIGNN versus weather/static ridge uses eleven scored station sites and four unscored sites. The v2r forecast-decoder comparison is a separate panel/population.
- **Captum:** use only primary `training_mean` baseline records for feature/time/heatmap summaries; display v2c h=1 and v2r h=6 outer-LOSO separately. All twelve input lags and all saved feature channels are retained. Additional baseline remains a sensitivity diagnostic. Source tensors are not regenerated.
- **City:** choose the earliest of the three frozen v2r forecast origins, `2025-10-08 07:00 UTC` (h=6 target `13:00 UTC`), independent of map appearance. Plot saved decoder values at their exact road-node coordinates, with station distance/convex-hull support. No smoothing or interpolation added.
- **Routing:** use original concentration scenario, same nine frozen demand batches (seeds 11/23/37 × 12/24/48), with common-admitted request comparisons. Perturbation panel uses all four prespecified fields. Show zero capacity violations and weak utilization explicitly; use an honest ±0.5% trade-off axis and annotate near-zero differences.
- **Visual style:** accessible blue/orange/green/purple palette, 8–9 pt text at 7.1-inch two-column width, 300-dpi PNG and vector PDF/SVG. Large road-edge topology may be rasterized inside PDF/SVG to control file size; all graph geometries still derive from stored edges.

Historical datasets and evaluation artifacts stay read-only. Derived plotting CSVs have source paths and hashes in the asset manifest. Missing values are rendered `--`, never zero. The old rejected-paper metrics are historical claims and are excluded from corrected-result graphics.
