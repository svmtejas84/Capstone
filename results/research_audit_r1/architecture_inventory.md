## Component status

- IMPLEMENTED AND TESTED: GINE+GRU station forecasts; wind-conditioned edge feature A; dense learned adaptive graph B; C arithmetic; λ=0 and Laplacian controls; SRTM node/edge experiments; station-attribute LOSO group-DRO (negative result).
- IMPLEMENTED BUT UNTESTED for the intended claim: full citywide inference with adequate per-node meteorology; no completed citywide forward pass on all nodes is evidenced.
- PROPOSED BUT NOT IMPLEMENTED: physically dimensioned traffic/emissions Q; mass-conserving advection-diffusion discretization; validated London/Copenhagen transfer.
- INVALIDATED BY AUDIT as a physical claim: interpreting C's source MLP as measured Q or its transport as a conservative physical operator.

## Preliminary comparable mechanisms

- Li, Yu, Shahabi, Liu, *Diffusion Convolutional Recurrent Neural Network: Data-Driven Traffic Forecasting*, ICLR 2018, [arXiv:1707.01926](https://arxiv.org/abs/1707.01926): directed diffusion graph operation plus recurrent temporal prediction. C does not implement DCRNN's random-walk discretization.
- Wu et al., *Graph WaveNet for Deep Spatial-Temporal Graph Modeling*, IJCAI 2019, [DOI:10.24963/ijcai.2019/264](https://doi.org/10.24963/ijcai.2019/264): learned node-embedding adaptive adjacency comparable to B's dense embedding matrix.
- Xu et al., *How Powerful are Graph Neural Networks?*, ICLR 2019, [arXiv:1810.00826](https://arxiv.org/abs/1810.00826): GIN aggregation family underlying GINE-style message passing. GINE's edge-attribute implementation here is provided by `torch_geometric.nn.GINEConv`.

These comparisons establish prior mechanisms, not an exhaustive novelty search. No architecture-specific mechanism has yet been shown to be unique relative to relevant graph forecasting and physics-informed controls.
